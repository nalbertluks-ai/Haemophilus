# Haemophilus — seminário de microbiologia

Apresentação interativa (Vite + Three.js + GSAP) sobre o gênero *Haemophilus*.
Nalbert Henrique, Moisés Davi e Edmund Jeffrey · Eixo CFSH · Faculdade de Medicina de Altamira · UFPA.

```
npm install
npm run dev      # http://localhost:5173
npm run build    # gera dist/
```

Controles: setas/espaço/passador de slides, teclas 1–9 por capítulo, F tela cheia, controle de Xbox.
Guia de apresentação em `docs/APRESENTAR.md`; créditos das imagens em `docs/CREDITOS.md`.
